# Animated Portfolio (React + Vite)

    npm install
    npm run dev      # local dev server
    npm run build    # production build in /dist

Edit your details in `src/components/*` (name, bio, projects, email) and the
colours/fonts in `src/styles.css`. Scroll/cursor logic lives in `src/engine.js`.
To use a real photo, replace the two `<svg><use href="#p"/></svg>` faces in
`Hero.jsx` with `<img src="/me.jpg" />` (put the image in `/public`).
